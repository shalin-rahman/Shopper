# Shopper Constitution

This project is a multi-tenant ERP and POS platform for Bangladeshi businesses. The business requirements are authoritative and must remain traceable to implementation work.

Core principles:
- Requirements before implementation.
- Business behavior and acceptance criteria come before code structure.
- Tenant isolation and financial integrity are non-negotiable design constraints.
- Documentation and tests must stay aligned with the requirements.
- Existing repository evidence must be preserved when updating the spec; this repo’s docs are not to be overwritten without justification.
